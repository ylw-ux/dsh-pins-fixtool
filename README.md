# dsh-pins — 把对话里的段落固定到右侧栏

在 DeepSeek Harness 的对话界面里**划选一段文字**，浮出来的动作条里点「固定」，这段内容就会进入**右侧栏**的固定片段列表：像便签一样每屏排 8-10 条，点击任意一条可以跳回原文并高亮。

解决的是这个场景：让模型解读长文档/论文代码时，回复很长甚至跨多轮，来回滚动找上下文会打断思路——把关键结点固定下来，就等于给这段对话建了一份"上下文骨架"。

## 怎么用

| 操作 | 效果 |
|---|---|
| 划选文字 | 选区上方浮出动作条：**固定 / 加标签 / 复制** |
| `Alt` + `P` | 固定 / 取消固定当前选区（等同于点动作条） |
| 同上再划选同一段 | 该段已固定时，动作条显示「取消固定」 |
| 点侧栏卡片 | 滚回原文并高亮；右下角浮出「回到固定片段」 |
| 卡片上的 `#` | 打开标签行：已有标签显示为可点掉的胶囊，输入新标签回车即加 |
| 卡片上的 `⧉` / `✕` | 复制原文 / 取消固定 |
| 面板顶部「本对话 / 全部」 | 当前会话的固定 / 跨会话总览（两个视图的搜索与标签筛选一致） |
| 搜索框 | 同时匹配固定内容和标签；标签胶囊可点选筛选 |

右侧栏是 Harness 的标准右栏标签：第一次固定会自动把右栏展开，之后它就是「固定片段」这一个页签，可以和文件树、文档并排分屏。

## 设计要点

- **一条消息可以固定很多段**：去重按「消息 + 引文」判断，不是按消息——同一段回复里可以固定多个结点，这正是长回复拆提纲需要的。
- **每会话一份**：固定按会话隔离（右栏本身就是会话级的），另给「全部」视图做跨会话复盘。
- **原文顺序优先**：默认按消息在对话中的顺序排列，而不是你固定的时间顺序——你脑子里的地图是文章结构，不是操作历史。
- **动态高度但有上限**：1 行内容就 1 行高，长的截到 3 行；超过 600 字的选区按前 600 字固定，完整文本仍可复制。
- **固定过的原文有持久标记**：优先用 CSS Custom Highlight API（不改 DOM），不支持时退化为本插件自己的 `<mark>`；标记只画当前会话。
- **锚点不存 DOM 位置**：标注靠 `消息 key（会话装配引擎的稳定 key）+ 引文 + 相对字符偏移`定位，遵循 W3C Web Annotation 的建议（绝对偏移在内容变化时必然漂移）。消息重新渲染、流式追加、历史分页都不会让固定失效。
- **文本索引与浏览器选区同算法**：索引把文本节点直接拼接、再按 `\s+ → 空格` 归一，与 `Range.toString()` 逐字符一致——这是高亮不错位的前提（markdown 的块级结构曾让我插入分隔符而错位）。
- **跳转写滚动容器而不是 `scrollIntoView`**：应用框架是 `overflow:hidden`、对话自己拥有唯一滚动口，让浏览器挑滚动容器会落点错乱。
- **样式只用主题 token**（`--dsw-alias-*` / `--dsw-specific-sidebar-fill`），不 import 任何 Harness 客户端包，亮/暗主题都跟随宿主。
- **失败不静默**：固定、取消固定、打开面板的每一步失败都会在界面下方浮出具体原因，而不是只写控制台。

## 数据与边界

- 数据存在浏览器的 `localStorage`，键 `dsh-pins/v1`。换浏览器、清站点数据会丢；因为它属于"浏览器的视图状态"，与 Harness 自己保存右栏布局的方式一致。
- 固定一个还没加载进窗口的历史消息（分页往上、或已被上下文压缩）时，点击会提示先向上滚动加载历史，而不是默默跳错地方。
- 选区跨两条消息时不会固定（避免存下一个语义不明的区间）；跨段落但在同一条消息内是支持的。

## 结构

```
package.json       清单（dsh.bundle.patch + dsh.client）
cordis.patch.yml   插入 host 行
index.js           Host 半边：注册 pinsHost 服务（预留导出/工具等 Host 能力）
client.js          浏览器半边：选区浮条 + 右栏面板 + 锚定/跳转 + localStorage
icon.svg           在插件管理器卡片上显示的图标
locale/{zh,en}.json 插件显示名与描述
```
